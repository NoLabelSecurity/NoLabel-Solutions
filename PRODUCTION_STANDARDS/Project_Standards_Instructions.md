# Project Standards Instructions

This document provides the operational guidelines and production standards for this web application repository.

Primary Website Production Standards are maintained in:
`/PRODUCTION_STANDARDS/WEBSITE_PRODUCTION_STANDARDS.md`

All development, modifications, audits, and documentation in this repository must adhere strictly to the 31 core standards sections defined in `WEBSITE_PRODUCTION_STANDARDS.md`:

1. **Repository Standards** - Maintain clean folder structure, naming conventions, and documentation in `/PRODUCTION_STANDARDS/`.
2. **Primary Objectives** - Prioritize correctness, safety, accessibility, security, performance, and maintainability.
3. **General Development Rules** - Preserve existing architecture, use minimal change principles, and maintain backwards compatibility.
4. **Project Discovery** - Verify business purpose, technology stack, and user flows before implementing changes.
5. **Legal & Compliance** - Ensure privacy policies, terms, cookie policies, and accessibility statements reflect actual site functionality and footer links function properly.
6. **Contact Forms** - Validate inputs, handle spam, protect against unsanitized submissions, and ensure accessible form controls.
7. **Accessibility (a11y)** - WCAG 2.1 AA compliance, keyboard navigation, semantic HTML, visible focus states, and aria attributes.
8. **SEO Standards** - Page titles, meta descriptions, structured JSON-LD schema, canonical tags, and mobile readiness.
9. **Security Standards** - Input sanitization, safe environment variable handling, no hardcoded secrets, and HTTPS assumptions.
10. **Performance Standards** - Code splitting, image optimization, responsive media, minimal bundle overhead, and sub-100ms UI interactions.
11. **UI/UX & Design Consistency** - Cohesive brand identity, typography hierarchy, responsive layouts, clear visual focus, and smooth motion states.
12. **Content & Copywriting** - Clear messaging, inclusive language, professional tone, and avoidance of placeholder text.
13. **Branding & Visual System** - Consistent palette, custom display typography, polished component states, and logo guidelines.
14. **Media & Asset Management** - Optimized assets, descriptive alt text, clean file organization, and appropriate formats.
15. **Analytics & Monitoring** - Privacy-first tracking, error handling, performance telemetry, and event logging.
16. **Integrations & Third-Party Services** - Secure API integrations, rate limiting awareness, timeout handling, and secret isolation.
17. **Internationalization & Localization** - Clean locale strategies, UTF-8 encoding, and accessible formatting.
18. **E-commerce Standards** - Secure product listings, cart workflows, clear pricing, and payment security (when applicable).
19. **Blog & CMS Standards** - Structured content models, clean rich text rendering, and revision handling (when applicable).
20. **AI Development & Hallucination Prevention** - Repository-first inspection, no fabricated APIs or metrics, and verified codebase context.
21. **Maintenance & Scalability** - Clean refactoring paths, low technical debt, and maintainable component contracts.
